# VoyageAI ✈️

An intelligent mobile-responsive **Travel Guide & Itinerary Planner** featuring destination highlights, tabbed navigation, and persistent packing checklists.

🔗 **Live Demo:** [View Live App](https://samikshachdry611-lgtm.github.io/travel-guide-app/)

## ✨ Features
- Mobile-first app frame UI with smooth tab navigation
- Destination search previewing landmarks and city photography
- Interactive day-by-day travel itinerary schedule
- Persistent smart packing checklist using `localStorage`
